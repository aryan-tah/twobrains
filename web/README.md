# web

* `delete.html` — Delete the Brain: autoplaying deletion story, live LIF simulation in `lif-worker.js`.
* `index.html` — TwoBrains scene: male and female brains over a courtship dish, replaying `data/*.json` runs.
* `index2d.html` — earlier 2D replay, kept for reference.

Serve with `python3 -m http.server 8000` from this folder. Data files are generated by the scripts in `../experiments`.
